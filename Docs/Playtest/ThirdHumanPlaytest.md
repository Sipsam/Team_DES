# Twin Edge V3 3차 사람 플레이테스트

## 다운로드 및 실행

1. 두 사람 모두 전달받은 같은 `V3Playtest-03-*.zip`을 내려받는다. 파일명에 **03**이 있는지 확인한다.
2. 인터넷에 연결된 Windows PC에서 **모두 압축 풀기**를 선택하고 쓰기 가능한 폴더에 푼다. 풀린 폴더에서 `V3Gameplay.exe`를 실행한다. 실행 파일과 함께 풀린 폴더 및 파일은 같은 위치에 둔다.
3. 두 사람 모두 게임에 표시할 닉네임을 입력한다. 한글 닉네임은 2~12자로 입력해 본다.
4. 방장(Host)은 **방 생성**를 선택하고 대기실에서 방 코드를 복사해 함께 테스트할 사람에게 보낸다. 참가자(Client)는 **방 참여**를 열어 코드를 입력한 뒤 **참여**를 누른다.
5. 대기실에서 서로의 캐릭터와 이름을 확인한다. 참가자가 **준비**를 누르고 방장이 **게임 시작**을 누른다. 3, 2, 1 표시가 끝나면 왕로에서 함께 출발한다.

## 기본 조작

- **WASD** 이동, **마우스** 시점, **Shift** 달리기, **Space** 점프, **E** 상호작용.
- **N** 미니맵 켜기·끄기, **M** 전체 지도 열기·닫기. 지도에서 구역과 층을 선택한다.
- **Esc**로 열린 화면을 닫거나 경기 메뉴를 연다. 경기 메뉴의 **조작법 다시 보기**에서 기믹 및 복로 조작을 확인한다. 화면에 표시되는 상황별 키 안내를 따라 진행한다.
- 메인 메뉴와 경기 메뉴의 **설정**에서 전체 음량, 화면 모드, 미니맵, 마우스 감도, 연출 효과 강도를 조절할 수 있다. 온라인 경기와 상대의 조작은 메뉴나 지도를 열어도 계속된다.
- 재입장을 확인할 때는 방장이 방에 남고 참가자만 **방 나가기** 후 같은 닉네임과 기존 방 코드로 다시 참여한다. 연결 문제를 확인한 경우 화면에 표시된 문구를 적는다.

## 두 사람이 확인할 항목

한 번 함께 플레이하면서 확인한 곳과 이상을 표시한다. 도달하지 못한 항목은 미확인으로 남긴다. 서로 체감이 다르면 각자 적는다.

### 세션

- [ ] 한글 입력기에서 조합과 확정이 자연스럽고 다시 실행했을 때 닉네임이 저장되어 있는가?
- [ ] 방 생성·참여, 캐릭터와 이름 구분, 준비·시작과 카운트다운이 이해하기 쉬운가?
- [ ] 연결 문제의 안내로 다음 행동을 알 수 있는가? 참가자가 나갔다 돌아왔을 때 같은 경기에서 조작을 이어갈 수 있는가?

### 게임플레이 및 밸런스

- [ ] 2차 테스트의 [기존 피드백 27개 묶음](SecondHumanPlaytest.md#두-사람이-확인할-항목)을 바탕으로 왕로 협동과 복로 경쟁에서 좋아진 점과 남은 문제를 적는다. 배포 ZIP의 `SecondHumanPlaytest.md`에서도 해당 체크리스트를 볼 수 있다. 실행은 위의 3차 안내를 따른다.
- [ ] 구간별 소요 시간, 실패·복구 횟수, 체감 난이도(1~5)를 간단히 적는다. PvP 공격·잡기·던지기·탈출이 읽히고 양쪽에 공정한가? 체크포인트와 추락 후 복구, 결승 판정이 예상과 같은가?
- [ ] **다리 별도 확인** · 복로의 후반 발판 점프에서 경고, 착지와 지지 판정이 간헐적으로 어긋나는지 본다. 어느 발판에서 어디로 뛰었는지 적는다.
- [ ] **막대 별도 확인** · 막대에서 지면으로 착지하거나 역할을 교대할 때 높이·위치가 튀거나 정지 자세로 바뀌는 타이밍이 어긋나는지 본다.

### UI 및 첫 플레이 안내

- [ ] 메뉴·대기실·닉네임·스태미나가 쉽게 읽히는가? 튜토리얼과 상황별 키 안내만 보고 다음 행동을 알 수 있는가?
- [ ] 미니맵과 전체 지도의 구역·층 전환을 이해하기 쉬운가? 상대와 보석이 공개되는 범위가 협동과 경쟁에 적절한가?
- [ ] 성채 키패드에서 버튼·숫자 키·삭제·확인과 정답·오답 반응이 이해되는가? Esc, 조작법 다시 보기와 설정을 필요할 때 찾을 수 있는가?

### 오디오

- [ ] 왕로와 복로의 음악 차이 및 구간별 환경음이 잘 들리는가? 발걸음과 캐릭터 음성이 상황에 맞는가?
- [ ] 공격 기합과 실제 타격음이 구분되는가? 함정·다리 경고, 봉인·보석 효과가 음악과 환경음 위에서도 들리는가? 전체 음량과 소리 간 균형을 적는다.

### 애니메이션 및 시각 효과

- [ ] 이동·착지 자세, 막대·목재·노와 손의 정렬, 막대 착지 후 정지 전환, PvP 피격 표현이 자연스러운가?
- [ ] 보석과 경기 전환 연출이 상황을 알려 주는가? 효과 때문에 캐릭터, 길, 경고가 가려지거나 눈이 피로한 곳이 있는가?

### 결과 및 재경기

- [ ] 양쪽의 승리·패배 화면과 전체 경기 시간이 판정과 맞는가? 중단했다면 경과 시간과 중단 구간을 적는다.
- [ ] 재경기 동의와 취소가 이해되는가? 두 사람이 동의하면 같은 방에서 새로 준비·시작할 수 있는가? 이전 타이머, 보석, 진행 상태나 UI가 남는가?

### 성능 및 안정성

- [ ] 각 PC의 CPU, 그래픽카드, RAM, 실제 화면 해상도와 창/전체화면 여부를 적는다. 정확한 사양을 모르면 아는 항목만 적는다.
- [ ] 프레임 저하, 전체 지도 표시 중 저하, 순간 멈춤, 지연, 연결 종료 또는 두 화면의 상태 불일치를 느낀 구간을 적는다. 크래시나 진행 불가가 발생했다면 정상 복귀 여부를 적는다.

## 문제 기록

| 항목 | 적을 내용 |
| --- | --- |
| 빌드·역할 | ZIP 파일명, 방장 또는 참가자. 양쪽에서 봤는지도 표시 |
| 구간·진행 단계 | 예: 다리 후반, 복로. 단계가 불명확하면 화면 문구나 마지막 행동 |
| 재현 방법 | 직전 행동부터 순서대로, 입력과 반복 횟수를 아는 만큼 |
| 예상 / 실제 | 무엇을 기대했고 화면·소리·조작에서 무엇이 달랐는지 |
| 첨부 | 가능하면 스크린샷이나 짧은 영상. 공유 전 방 코드와 개인 정보는 가림 |

경기 시간은 결과 화면의 값을 적는다. 문제가 없어도 특히 좋았던 점과 가장 불편했던 점을 하나씩 남긴다.
