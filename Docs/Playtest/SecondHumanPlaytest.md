# Twin Edge V3 2차 플레이테스트

## 실행 및 방 참가

두 사람 모두 인터넷이 연결된 Windows PC에서 같은 빌드를 사용한다. ZIP을 받았다면 쓰기 가능한 폴더에 모두 풀고 `V3Gameplay.exe`를 실행한다.

1. Host는 **Create room**을 누르고 **Copy**로 복사한 방 코드를 Client에게 전달한다.
2. Client는 코드를 붙여넣고 **Join room**을 누른다. 두 사람의 준비가 끝나면 경기가 자동으로 시작된다.
3. 화면을 클릭해 마우스를 잡고 WASD로 이동한다. Shift는 달리기, Space는 점프, E는 상호작용이다. Esc로 마우스를 풀고 방 메뉴를 연다. 연결 문제가 생기면 화면의 메시지와 발생 구간을 적는다.

## 두 사람이 확인할 항목

- [ ] **체크포인트와 복구** — 떨어지거나 리스폰한 뒤 두 사람 모두 예상 위치에서 조작을 이어갈 수 있는가?
- [ ] **카메라와 달리기** — 카메라를 돌린 뒤에도 WASD가 보는 방향에 맞는가? Shift 달리기의 속도와 스태미나가 적절한가?
- [ ] **협동 막대와 암석** — 막대 중심을 이동하고 역할을 바꿀 때 고도 차와 암석 충돌을 이해할 수 있는가? 캐릭터가 바위에 끼인 곳이 있었는가?
- [ ] **봉우리와 복로 발사** — 봉우리 경계와 라운딩에서 설 수 있는 곳을 읽기 쉬운가? R 발사 착지 예측이 실제 착지와 맞는가?
- [ ] **캐릭터와 PvP** — 외형과 망토 색으로 상대를 구분할 수 있는가? 공격, 잡기, 던지기, 탈출의 결과가 이해되는가? 잡는 쪽과 잡힌 쪽의 이동 및 카메라는 어떤가?
- [ ] **다리와 계단** — 접근 시 붕괴 다리의 전조와 타이밍을 읽을 수 있는가? 직선 계단을 양방향으로 통과하기 쉬운가?
- [ ] **뗏목** — 피격을 즉시 알아볼 수 있는가? 장애물의 밀도와 회피 난이도가 적절한가?
- [ ] **성채와 지하 통로** — 안내와 기록을 읽고 다음 행동을 알 수 있는가? 발판과 계단, 지하 통로의 길이 잘 보이는가?
- [ ] **지하 함정과 협동 점프** — 양쪽 레인에서 함정 전조와 버튼 접근 지점이 보이는가? 25초 안에 호흡을 맞춰 점프할 수 있는가?
- [ ] **하수도** — 정답 버튼의 눌림과 표시가 양쪽에 보이는가? 오답 뒤 기존 진행을 유지하며 즉시 재입력할 수 있는가? 12문양 승인 후 양쪽 우회로를 통과할 수 있는가?

## 경기 기록

두 사람의 조작 체감이 다르면 각자 의견을 남긴다. 실패에는 추락, 리스폰, 퍼즐 재시도와 연결 끊김을 포함하고 메모에 종류를 적는다. 종료 화면의 **전체 경기 시간**을 적는다. 중단한 경우 경과 시간과 중단 위치를 적는다.
