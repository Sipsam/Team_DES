# Twin Edge V3 프레젠테이션 설계

V3-PRES-01 사용자 승인 기준. 이후 화면, 음향과 연출 구현은 이 문서와 [로드맵](../Workflow/ROADMAP.md)을 따른다. 경기 규칙은 [최신 통합 기획서](TwinEdge_Latest_GamePlanning_IntegratedSummary.pdf)와 [현재 런타임 계약](../Architecture/GameArchitecture.md)을 함께 참조한다. [Presentation Audit](PresentationAudit.md)은 승인 전 구현 현황과 자산 조사 기록이다.

작업 환경의 팀 상세기획서 `TwinEdge_Level_UI_Design.pdf` 1~6쪽을 직접 확인했다. 4~6쪽의 최소 HUD, 좌측 하단 상황별 키 안내, 우측 하단 스태미나 및 저채도 소재 방향을 반영했다. 대기실 수동 시작과 미니맵은 V3-PRES-03 최신 승인 사양을 적용한다. 상세 PDF는 로컬 팀 원본이므로 공유 클론은 이 문서와 추적 중인 통합 기획서를 참조한다.

## 승인 사항

| 영역 | 기준 |
| --- | --- |
| A · UI | 한국어 UI만 지원하며 브랜드명 **TWIN EDGE**는 원문으로 표기한다. 심볼과 텍스트를 조합한 로고, 나무·석재·양피지 포인트, 미니멀한 장식, 실시간 3D 월드 배경, 짧은 페이드의 메뉴 전환과 uGUI를 사용한다. |
| B · 메뉴와 로비 | Client의 준비 확인과 Host의 명시적인 시작 요청을 적용한다. 랜덤 망토 색상을 유지한다. 플레이어별 3D 캐릭터 미리보기, 닉네임 입력과 전용 로딩 화면을 제공한다. 재입장은 기존 수동 재입장 흐름을 사용하고 안내를 개선한다. |
| C · HUD와 튜토리얼 | 우측 상단에는 13% 화면 너비의 북쪽 고정 원형 미니맵을 둔다. M 전체 지도와 N 표시 토글을 제공하고 두 캐릭터의 머리 위에 승인 닉네임을 표시한다. 우측 하단 작은 가로 스태미나 바에 숫자를 표시하지 않는다. 경기 시간은 결과 화면에 표시한다. 기믹 진행은 월드 표현과 상황별 HUD를 함께 사용한다. 최초 접근 시 상황별 튜토리얼을 제공하고 다시 볼 수 있게 한다. 체크포인트 활성화와 보석 획득·탈취는 각 월드 효과와 일시적 메시지로 알린다. |
| D · 음악과 음향 | 중세 판타지·앰비언트 음악을 사용한다. 왕로는 평화로운 탐험, 복로는 긴박한 분위기로 전환하고 구간별 음악 분위기와 공간 환경음을 구성한다. 상황에 따라 음악을 동적으로 전환하고 캐릭터의 짧은 신음·기합을 사용한다. 사용권이 확인된 무료 또는 오픈소스 음원을 우선한다. |
| E · 경기와 결과 | 짧은 시작 카운트다운, 공동 봉인 해제 VFX·SFX 강화, 최초 보석 획득 시 복로 전환 연출을 제공한다. 복로 전환 중 현재 카메라 시점을 유지하고 연출 중 플레이어 조작을 일시 제한한다. 승패 캐릭터 애니메이션을 사용하고 결과에 승패와 경기 시간을 표시한다. 결과 이후 메인 메뉴 복귀와 재경기를 지원한다. |
| F · 설정과 편의 | Master 음량, 전체화면/창모드, 마우스 감도, 카메라 흔들림 등 연출 강도 및 비활성화를 제공하고 로컬에 저장한다. 그래픽 프리셋, 해상도 선택, 키 바인딩 변경은 범위에서 제외한다. |
| G · 애니메이션과 VFX | 로우폴리 스타일과 중간 수준의 효과 강도를 사용한다. 공격 타격, 소규모 이동과 착지, 보석 발광과 파티클을 적용한다. 기존 캐릭터 모션을 우선 활용하며 기믹 상호작용 자세와 손·도구 정렬을 개선한다. |

## uGUI 공통 자원

- [PresentationRoot](../../Assets/Game/UI/Runtime/PresentationRoot.cs)는 1920×1080 기준 Screen Space Overlay Canvas와 Screen, Overlay, Modal 레이어를 제공한다. 각 화면은 해당 레이어 아래에서 앵커와 LayoutGroup으로 구성한다. `ShowScreen`, `ShowOverlay`, `ShowModal`로 화면 교체와 입력 소유를 지정한다. 수동 월드 클릭을 통한 재캡처 흐름을 이용한다. 페이드는 불투명한 시점에 화면을 바꾸며 편도 140ms다.
- [UiKit](../../Assets/Game/UI/Runtime/UiKit.cs)은 브랜드 조합, 텍스트, 패널, 버튼, 필드, 상태와 오류, 모달, 진행바, 키캡, 로딩을 제공한다. 일반·호버·누름·선택·비활성의 색상과 측면 마커 형태를 함께 사용한다. 상태 카드에는 의미가 드러나는 한국어 레이블을 붙인다. 텍스트 스타일 토큰은 본문 26, 보조 22, 제목 44, 소제목 32 단위다.
- [PresentationTheme](../../Assets/Game/UI/Runtime/PresentationTheme.cs)은 배경 `#252320`, 나무 `#594333`, 석재 `#77736C`, 양피지 `#D8C7A5`, 기본 글자 `#F2EBDB`, 보조 글자 `#B5ADA0`, 강조 `#C5A268`, 협동 `#6489A6`, 경쟁 `#A64B45`, 경고 `#D28A42`, 성공 `#71946C`를 정의한다. 석재와 의미 색상은 작은 표식과 테두리에 쓰고, 단색 바탕 위에서 글자 대비를 확보한다.
- [TWIN EDGE 심볼](../../Assets/Game/UI/Art/TwinEdgeEmblem.png)은 이 프로젝트를 위해 만든 교차한 두 검과 중앙 보석의 조합이다. 256px 투명 Sprite와 `UiKit.Brand`의 한 줄 워드마크를 사용한다.
- 프로젝트 자산을 조사한 뒤 공식 경량 한국어 OTF인 Noto Sans KR Regular 2.004를 도입했다. uGUI의 임포트된 동적 Font와 Text/InputField를 사용하며 문구는 화면에서 수정한다. [공식 배포 파일](https://github.com/notofonts/noto-cjk/blob/Sans2.004/Sans/SubsetOTF/KR/NotoSansKR-Regular.otf)
- 폰트 원본을 게임에 포함해 재배포할 수 있는 SIL OFL 1.1이다. 폰트를 단독 판매할 수 없으며 재배포 시 저작권 문구와 라이선스 전체를 포함해야 한다. 폰트를 참조하는 향후 배포본에는 이 고지 파일을 동봉한다. [저작권 및 OFL 전문](../../Assets/Game/UI/Fonts/OFL.txt)

| 책임 | 활성 경로와 후속 화면 연결 |
| --- | --- |
| 화면 표현 | `SessionPresentation`이 메인 메뉴, 방 참여, 대기실, 로딩, 결과, 공통 설정, 경기 중 Esc 메뉴와 성채 키패드를 표시한다. `GameplayPresentation`이 경기 HUD와 이름표, 튜토리얼과 알림을 표시한다. `CourseMapPresentation`과 `MatchTransitionPresentation`이 지도와 경기 전환을 맡는다. |

| Phase와 진행 | `GameStateManager`와 서버가 사용자 준비, 경기 시작 승인, 런타임 준비, 경로 단계, 경기 시간과 승자를 결정한다. 각 기믹과 체크포인트·보석 런타임이 진행 데이터의 소유자다. |
| 상호작용 | `PlayerInteraction.CurrentTarget`, 기믹별 Prompt/Hud와 `GameplayCharacter`가 현재 대상과 상태를 제공한다. 새 안내는 여기에서 읽을 수 있는 표현 데이터를 사용한다. |
| 커서와 카메라 | V3에서 `SessionPresentation`이 Esc 화면 전환을 맡고 `ThirdPersonCamera`가 월드 클릭 캡처를 맡는다. `GameplayInput`이 캡처 상태를 확인한다. Root는 입력 화면·모달·페이드가 열린 동안 게임 입력을 차단하고 모달이 닫히면 이전 UI 포커스를 복원한다. 마지막 입력 화면이 닫히는 프레임에는 게임 입력을 제한한다. |
| 진단 | `V3GameplayBootstrap.OnGUI`의 F3 진단과 Relay 검증 Driver는 `UNITY_EDITOR \|\| DEVELOPMENT_BUILD` 범위다. Showcase는 Editor 전용이다. |

## V3-PRES-02 메뉴와 대기실

- 랜딩과 방 참여는 저장된 V3 성채와 산악을 전용 카메라로 보여 준다. 메뉴와 경기 카메라는 화면 렌더링과 AudioListener를 함께 전환한다. 대기실 캐릭터 미리보기에는 AudioListener가 없다.
- 닉네임은 앞뒤 공백을 정리하고 NFC로 정규화한다. 표시 문자 2~12자와 NGO `FixedString64Bytes`의 UTF-8 용량을 각각 검사한다. 마지막으로 제출한 닉네임을 로컬에 저장한다. 서버가 연결 승인에서 같은 규칙을 적용하고 스폰된 캐릭터의 슬롯과 함께 복제한다.
- 대기실은 복제된 슬롯과 준비 상태를 보여 준다. 각 슬롯의 렌더 타깃에 실제 캐릭터의 메시와 Idle을 렌더링한다. 기존 서버 망토 배정이 복제되기 전에는 ‘망토 배정 대기’를 표시한다. 화면에서 나가면 미리보기 카메라와 렌더 타깃을 해제한다.
- 로딩 화면은 월드 준비, 방 생성·연결, 경기 시작 준비에 맞춰 상태 문구와 반복 표시를 제공한다. Client가 준비를 선택하면 Host가 게임 시작을 요청할 수 있다. 서버가 승인하면 두 피어의 월드, 스폰, 카메라 준비를 확인한 뒤 경기 카메라에 시작 카운트다운을 표시한다. 자동 시작 정책은 폐기한다.

## V3-PRES-03 지도 및 상황별 UI

- 지도는 +X 동쪽과 +Z 북쪽을 유지한다. 자신은 미니맵 중앙에 위치하고 방향을 화살표로 표시한다. 화면 높이의 32%를 최대 지름으로 적용한다. N으로 표시를 전환하고 로컬 `TwinEdge.MinimapVisible`에 저장한다. M으로 전체 지도를 열고 M 또는 Esc로 닫는다. 전체 지도에서 월드 개요와 구역·층을 선택한다. 지도 모달은 로컬 입력을 소유하며 온라인 경기는 계속 진행된다.
- 공개 마커는 양 Phase의 자신, 상대, 보석, 목적지, 체크포인트, 주요 기믹, 봉우리와 결승이다. 보석이 소유 상태이면 소유자 마커에 붙인다. 원 밖에서는 상대, 보석, 목적지의 방향을 우선한다. 실내 다른 층의 공개 동적 대상에는 높이 방향을 표시한다. 안개, 자동 경로, 막대 그래프, 강 장애물, 함정, 하수도, 퍼즐 정답과 상대 방의 비공개 단서를 표시하지 않는다.
- 우측 아래는 수치 없는 스태미나 게이지다. 좌측 아래는 현재 입력과 기믹의 역할·진행을 표시한다. 상단 중앙에는 체크포인트 활성화·복구와 보석 상태 변화의 짧은 알림을 표시한다. 기존 서버 상태를 사용하며 접속 직후 복제 상태는 알림 기준값으로 사용한다.
- 첫 접근 안내는 로컬 방 ID와 현재 경기 화면의 수명으로 관리한다. 리스폰과 같은 방 재입장 시 보존한다. Esc 메뉴의 조작법 다시 보기에서 다시 확인할 수 있다. 닉네임은 애니메이션 머리 기준에 투영하고 60m 밖이나 지형·벽에 가려지면 숨긴다.

## V3-PRES-04 핵심 효과음

- 현재 승인된 UI·기믹과 서버 이벤트에서 핵심 효과음을 재생한다. 함정 전조에 높은 우선순위를 부여하고, 사적인 퍼즐 입력 결과는 입력자에게만 전달한다.
- 설정 화면은 기존 Master 0–100 API를 사용한다. 음악, 환경음과 캐릭터 음성에도 이 값이 적용된다. [오디오 구조와 저장 계약](../Architecture/AudioArchitecture.md)

## 공통 설정과 Esc 메뉴

메인 메뉴와 인게임 Esc 메뉴는 같은 한국어 설정 화면을 연다. 기본값 복원은 확인을 거쳐 아래 설정만 바꾼다. 모든 값은 로컬 PlayerPrefs에 저장한다.

| 설정 | 기본값과 범위 | 저장 키 및 적용 책임 |
| --- | --- | --- |
| 전체 음량 | 100%, 0–100% | `TwinEdge.Audio.MasterPercent`, `AudioService.MasterPercent`와 `SetMasterPercent(int)` |
| 화면 모드 | 창모드, 전체화면 | `TwinEdge.DisplayFullscreen`, `LocalPresentationSettings`가 Windows 전체화면 창과 창모드를 적용 |
| 미니맵 표시 | 켜짐 | `TwinEdge.MinimapVisible`, `CourseMapPresentation.MinimapVisible`을 HUD, N키와 설정에서 공유 |
| 마우스 감도 | 100%, 10–200% | `TwinEdge.MouseSensitivityPercent`, `ThirdPersonCamera`의 기존 마우스 델타 배율 |
| 연출 효과 강도 | 100%, 0–100% | `TwinEdge.EffectIntensityPercent`, `LocalPresentationSettings.EffectPercent` 및 `MatchTransitionPresentation.EffectIntensity` |

화면 모드는 현재 렌더 크기를 요청하고 이전 창 크기를 복원에 사용한다. 모드 변경을 15초 안에 확인하면 재실행에 사용할 값을 저장한다. 취소, Esc, 시간 초과는 이전 모드와 크기를 요청한다. 명시적인 화면 모드 실행 인수가 있으면 해당 실행의 인수를 우선한다. 모드 변경은 Windows Player에서 제공한다.

연출 강도는 전환 화면 강조와 페이드, 선택적 조명·발광·장식 파편에 적용한다. 0%에서도 카운트다운과 필수 배너는 표시한다. 서버 시각과 입력 승인, 함정·붕괴 전조, 착지 링, 스태미나, 지도, 필수 마커와 퍼즐 진행은 강도 설정과 독립적이다.

Esc는 확인 모달, 조작법과 전체 지도, 설정과 경기 메뉴 순으로 열린 화면을 먼저 처리한다. 경기 중 키패드, 막대, 목재, 뗏목, 지하 참여와 산악 발사 충전은 기존 취소 입력을 우선 사용한다. 일반 플레이 중 Esc는 로컬 입력만 제한하며 서버 경기 시간과 상대 조작은 계속 진행된다. 방 나가기 확인은 Host와 Client 안내를 구분하고 기존 세션 종료 경로를 호출한다.

### 성채 키패드

- 서버가 E 상호작용을 승인하면 성채 키패드를 공통 모달로 연다. 버튼과 숫자 키가 한 입력 값을 편집한다. 삭제 또는 Backspace로 마지막 자리를 지우고 네 자리에서 확인을 누른다. 제출 후 서버 응답을 기다리며 오답이면 현재 입력에서 수정할 수 있다. 승인되면 키패드가 닫히고 기존 HUD가 내 확인 여부와 양쪽 진행을 표시한다.
- Esc 또는 닫기는 키패드만 닫는다. 닫는 클릭은 게임에 전달되지 않으며 이후 월드 클릭으로 마우스를 다시 캡처할 수 있다. 다른 모달이 입력을 소유하는 동안 새 키패드 요청은 화면을 가로채지 않는다. 유효 거리 이탈, 리스폰, 경기 상태 변경과 연결 종료는 로컬 입력을 정리한다.
- 서버의 기존 방 배정과 번호 수집·검증, 오답과 효과음 수신자, 문 개방 및 재입장 복원 계약을 사용한다. 키패드에는 입력자가 누른 숫자만 표시한다. [성채 게임플레이](../Architecture/GameplaySystems.md#연출-중-입력)

## V3-PRES-05 음악과 공간 음향

- 메뉴와 방 흐름에는 신비로운 테마 하나를 사용한다. 왕로는 산악 탐험, 협곡 협동, 강 항해, 성채 탐색 및 지하 탐험을 구분한다. 복로는 지하·성채·다리의 추격과 강·산악의 경쟁에 테마를 사용한다. 첫 보석을 획득해 서버가 Return을 확정하면 전환한다. 봉인 해제에서 왕로 테마를 유지하고, 이후 보석 상태가 바뀌어도 재생 위치를 유지한다.
- 음악은 각 피어의 실제 구역을 사용하며 서버 Phase와 승패로 전환을 결정한다. 결과에는 기존 승패 효과음과 각 결과의 음악을 함께 사용한다. 바람, 물, 성채 내부와 동굴의 배경음을 구분하며 강 수면, 복로 강의 비, 용암과 활성 화염에 거리 감쇠를 적용한다.
- 실제 이동과 접지로 발걸음, 점프와 착지를 재생한다. 공격 기합, 실제 피격 신음, 던지기와 발사 기합을 짧게 사용한다. 막대, 목재, 뗏목과 복로 발사에는 기존 승인·이동 상태의 피드백을 추가한다. [트랙 매핑과 전환 계약](../Architecture/AudioArchitecture.md#코스-음악과-환경음)

## V3-PRES-06 경기 시작과 전환

- 경기 카메라에 서버 시각 기준으로 3, 2, 1을 표시한다. 3초가 지나면 조작과 타이머를 시작하며 협동 색상으로 ‘왕로 시작’과 ‘서로 협력하여 보석을 찾으세요.’를 표시한다.
- 공동 봉인 해제 승인 후 1.5초 동안 ‘공동 봉인이 해제되었습니다’와 제단의 청백색 조명 및 크리스털 확산 효과를 표시한다. 첫 보석 획득 승인 시 2초 동안 경쟁 색상의 ‘복로 시작’, 짧은 화면 강조와 금빛 크리스털 효과를 표시한다. 서버가 확정한 획득 슬롯에 따라 보석을 지키거나 빼앗으라는 안내를 선택한다.
- 연출은 기존 카메라의 HUD 위에 표시한다. 제한 구간에는 상황별 상호작용 및 튜토리얼 안내를 정리하고 스태미나, 이름표 및 지도 정책을 유지한다. V3-PRES-08은 로컬 `MatchTransitionPresentation.EffectIntensity`로 조명, 크리스털, 화면 강조 및 페이드를 조절할 수 있다. 연출 시간과 조작 승인에는 서버 구간을 적용한다. V3-PRES-07은 기존 `Finished`, 승자 및 확정 경기 시간을 읽는다.

## V3-PRES-07 결과와 재경기

- E6 결과 화면은 서버가 확정한 승패, 승인 닉네임, 정지된 경기 시간을 읽는다. 시간은 MM:SS로 표시하고 한 시간부터 HH:MM:SS를 사용한다. 승리는 금빛, 패배는 밝은 적색과 한국어 텍스트로 구분한다.
- E7 결과 전용 캐릭터는 대기실과 같은 렌더 구조에서 원본 FBX의 Victory 또는 Defeat를 한 번 재생하고 종료 포즈를 유지한다. 서버가 배정한 망토를 적용한다. 결과 전환은 공통 140ms 페이드와 커서를 사용하고 기존 스트림의 HUD, 지도 및 키패드를 숨긴다.
- E8 두 참가자가 동의하면 같은 방에서 새 대기실을 구성한다. 먼저 동의한 참가자는 상대의 응답을 기다리거나 취소할 수 있다. 메인 메뉴는 기존 방 나가기를 사용한다. 새 경기는 준비·시작 버튼과 카운트다운을 거쳐야 한다.

## V3-PRES-09 애니메이션과 효과

- 실제 변위에 따라 Idle, Walk, Run을 재생한다. 1.5배 Run 재생 속도를 유지하고, 점프 클립의 포즈를 도약·공중·낙하·착지에 맞춰 사용한다. 일반 착지는 충분한 비접지 시간과 높이 낙차가 필요하다. 복로 산악의 강한 착지는 서버 승인 상태를 사용한다.
- 막대와 목재는 잡고 있는 쪽의 월드 모델을 기준으로 양손을 정렬한다. 목재는 정지, Walk_Carry와 빠른 운반의 Run_Carry를 사용한다. 뗏목은 복제된 탑승 위치와 구동 상태를 읽어 손·노를 함께 움직인다. 실제 승인된 성채 버튼 및 지하 스위치에는 짧은 팔 동작을 표시한다.
- 공격 궤적은 승인된 공격 자세에, 피격 파편은 별도의 실제 피격 시각에 연결한다. 기존 잡기·저항·던지기 자세와 피격 반응을 유지한다. 지면 효과는 실제 지지점과 표면을 사용한다. 목재 설치·붕괴, 막대 착지, 산악 발사, 뗏목 항적·노 물보라·충돌의 장식 출력은 기존 사건을 읽는다.
- 보석은 서버 상태와 revision으로 획득·드롭·재배치를 구분한다. 소유자 모델과 지도 공개 규칙을 유지한다. 짧은 PickUp은 정지한 캐릭터에만 재생하며 이동하면 해제한다. 봉인 및 최초 복로는 기존 크리스털 연출을 사용한다. 체크포인트는 기존 승인 HUD 알림을 사용한다.
- 장식 효과는 로컬 연출 강도에 따라 줄어들고 0%에서 사라진다. 함정·붕괴 전조, 예측 링, 피격 자세, 퍼즐·보석 식별, 지도·HUD·카운트다운은 기존 규칙을 유지한다.
