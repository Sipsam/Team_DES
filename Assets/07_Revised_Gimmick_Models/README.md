# 기믹 수정 모델 1차 검토본
Unity에서 Assets/07_Revised_Gimmick_Models/RevisedModelReview 씬을 여세요. Hierarchy에서 모델 선택 후 Scene 창에서 F로 확대하세요.
01_Bridge: 직사각형 널빤지 2.4 × 0.48, 두께 0.16. 아치틀 Slot_01~20. 0.6 간격, 총 길이 약 12, 중앙 높이 1.4. 빈 틀과 완성 예시는 별도 프리팹.
02_River: 턱 분리형 괴물물고기 신규 후보, 물 표면, 깔때기형 소용돌이.
03_Door_Opening: 벽에 끼운 전달돌, 물/돌/가시 문양 버튼, 문 앞 배치용 발판 3개 세트. 물 문양은 파랑 물결로 해석했습니다. 벽 양면으로 정보 전달하는 실제 이동 제한과 정답 순서는 별도 구현입니다.
04_Traps: 철제 격자 화염분출구, 분리된 SpikeLift, RollingRock, 용암 표면.
FantasyJaw.SetOpen(0~1)로 턱 각도 제어. 배치 프리팹 preview는 꺼져 있고 검토 씬에서만 자동 여닫기.
물/용암/소용돌이는 FacetWaterLava.shader와 삼각형 메시. 물은 아직 강 전체가 아닌 원형 표면 샘플이며 맵에 맞는 범위 조정 필요.
불 파티클 외 가시 상승·돌 구르기·피해·퍼즐 판정·다리 설치는 모델 부품을 이용해 스크립트 담당이 연결해야 합니다.
OBJ/MTL은 정적 외형만 포함합니다. 턱 동작·셰이더·파티클까지 확인하려면 prefab/Unity 씬을 사용하세요.
현재는 1차 외형 검토본입니다. 개별 확대 검토와 실제 플레이 검증 전이므로 현재 진행상황 전달용 ZIP에 포함했습니다. 최종 완성 승인본을 뜻하지 않습니다. 기존 05 폴더 모델은 보존했습니다.
